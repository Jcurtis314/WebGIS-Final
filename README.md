# [My Web GIS Map - Lab 6 Final JC] 

  

## Description 

This web map shows An overview of North America and highlights significant cities in the United States. 

It was built using Leaflet.js as part of GIS 5220/420 Lab 6. 

  

## Data Source 

The data used in this map comes from [Open Street Maps, US Census Bereau]. 

  

## Features 

- Interactive basemap with zoom and pan 

- [GeoJSON point features that highlights US cities] 

- [Clickable pop ups that shows information on the specific cities selected] 

- Scale bar showing metric and imperial units 

  

## Technologies Used 

- HTML5, CSS3, JavaScript (all in one index.html file) 

- Leaflet.js 1.9.4 

- OpenStreetMap tiles
